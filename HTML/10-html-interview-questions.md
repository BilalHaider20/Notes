# 10. HTML Interview Questions

## Beginner questions
1. What is HTML?
2. What is the purpose of `<!DOCTYPE html>`?
3. What is the difference between `head` and `body`?
4. What is the difference between block and inline elements?
5. What is the purpose of the `alt` attribute?
6. What is the difference between `div` and `span`?
7. What is semantic HTML?

## Intermediate questions
1. What is the difference between `section` and `article`?
2. Why is `label` important in forms?
3. What is the difference between GET and POST?
4. What is the difference between `id` and `class`?
5. What is the difference between `id` and `name`?
6. Why should tables not be used for layout?
7. What is the difference between `button` and `a`?
8. What is the purpose of the viewport meta tag?

## Advanced questions
1. What is the DOM?
2. What is the difference between HTML attributes and DOM properties?
3. What is the difference between `async` and `defer`?
4. What is ARIA?
5. When should you use empty alt text?
6. What is progressive enhancement?
7. What are `data-*` attributes?

## Short answer revision
### What is semantic HTML?
Using meaningful HTML tags that describe the purpose of the content.

### Why is accessibility important?
It makes websites usable for more people and improves quality.

### Why is `defer` often preferred?
Because it allows HTML parsing to continue and runs scripts after the page structure is parsed.

## Interview tips
- Do not only memorize definitions
- Explain with small examples
- Focus on semantic HTML and accessibility
- Be clear about forms and script loading
- If asked about advanced topics, answer simply and confidently

## Practice challenge
Try to build:
- a semantic webpage
- a form with labels and validation
- a table with proper structure
- an image section with alt text and figure caption

That practice alone will make many interview answers easier.
