# 07. SEO and Metadata

## What is metadata?
Metadata is information about the page.
It is placed inside the `head` tag.

## Important meta tags
### Character set
```html
<meta charset="UTF-8" />
```
Tells the browser how to read text characters.

### Viewport
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```
Important for responsive design.

### Description
```html
<meta name="description" content="Learn HTML with simple interview notes." />
```
Often used by search engines.

## Title tag
```html
<title>HTML Interview Notes</title>
```
Very important for SEO and browser tabs.

## Semantic HTML and SEO
Search engines understand content better when semantic HTML is used.
This is one more reason to use tags like `main`, `article`, and headings correctly.

## Canonical tag
Used to tell search engines which page version is the main one.
```html
<link rel="canonical" href="https://example.com/html-notes" />
```

## Open Graph tags
Used for social sharing previews.
```html
<meta property="og:title" content="HTML Interview Notes" />
<meta property="og:description" content="Beginner-friendly HTML notes for interview prep" />
<meta property="og:image" content="https://example.com/cover.jpg" />
```

## Why headings matter for SEO
Good heading structure helps search engines understand content hierarchy.

## Interview questions
### What is the purpose of the viewport meta tag?
It helps pages display correctly on mobile devices.

### Why is the title tag important?
It is important for SEO, browser tabs, and search engine results.

### What is metadata in HTML?
Metadata is page information placed inside the head tag.

## Quick revision
- Know `title`, `meta charset`, `meta viewport`, and description
- Understand the SEO value of semantic HTML
